# 沖繩旅遊手冊 2026.11.07 – 11.14

給旅伴共用的行程手冊，單一 HTML 檔、無後端。

- 航班、住宿、每日行程框架
- 互動地圖（Leaflet + OpenStreetMap）
- 行李清單（勾選狀態存在各自裝置）

## 要新增景點／餐廳

編輯 `index.html` 最下方的 `PLACES` 陣列，加一筆就會同時出現在地圖與候選清單：

```js
{ type:"spot", name:"美麗海水族館", lat:26.6941, lng:127.8780, note:"建議停留 3 小時" },
```

`type` 可用 `airport` / `hotel` / `spot` / `food`。

排進每日行程則編輯 `DAYS` 陣列對應日期的時段。`name` 與 `PLACES` 相同時，候選清單會自動標示「已排入行程」。
